# Citable Publication

A deterministic publishing gate for equivalent HTML, Markdown, and JSON.

## Problem

A page can have the right canonical URL while losing a code block or table in
its machine-readable representation. Publication needs content-level checks.

## Scope

Project 01 of the engineering evidence series. One structured English corpus
produces three representations, stable section citations, and a file manifest.

## Quick start

Implementation and verified commands are being added in focused commits.

## Usage

The command-line interface builds and verifies a publication directory.

## Architecture

Strict source validation precedes deterministic rendering and publication checks.

## Reproduction

The experiment compares a canonical-only baseline with the full publication gate.

## Results

Results will be recorded after the implementation and fault-injection tests run.

## Testing

Tests cover valid content, invalid schemas, representation drift, and the CLI.

## Limitations

This project evaluates its supported document model, not arbitrary websites.
