# Contributing

Describe the failure or proposed behavior in an issue. Keep changes focused and add a regression test that fails before the correction.

Run the README Testing commands and reproduce the fault matrix. Update the contract and limitations when behavior changes. Keep new corpus data original or include an explicit redistribution license.

Use English, avoid em dashes, and limit code comments to non-obvious decisions. Put longer explanations in documentation. Follow AGENTS.md.

Never edit recorded evidence to obtain a desired outcome. Commit implementation changes before rerunning experiments so each report identifies the tested revision. Keep environment differences visible.
