# Repository rules

Use English for all repository content. Do not use em dashes.
Keep comments sparse and explain design decisions in documentation.
Make small, focused commits using the configured Git identity.
Do not add assistant attribution or co-author trailers.
Run the complete verification suite before publishing a release.

# Series completion gate

Finish this project before starting the next repository in the series.
A finished project has working code, meaningful tests, passing remote CI,
a reproducible experiment, raw results, documented limitations, and an
open-source release in a public repository.

# Shared README sections

Problem, Scope, Quick start, Usage, Architecture, Reproduction, Results,
Testing, Limitations, Contributing, License.
